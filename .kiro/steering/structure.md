# Structure

```
src/core/            pure logic, no DOM, no network
  bytes.ts             base32 (strict), base64url, bit reading
  words.ts             BIP-39 word encoding with a SHA-256 checksum
  cards.ts             card byte layouts: shard (0x01), seal (0x02), key (0x03); QR text "PH1-…"
  jar.ts               seal, open, letters, verifyCircle, openWithKey, resealJar, parseJar
  buddy.ts             costume + emblem per card, from jar id and x
  watch.ts             runWatch (the schedule), message texts
  core.test.ts         property tests for all of the above
src/watch-service/   the only server code
  service.ts           create, confirm, check in, pause, opt out, keep jar, tick
  http.ts              Request → Response routes under /api/watch
  adapters.ts          MemoryStore, OutboxMailer, ResendMailer
  service.test.ts      with a fake clock
src/ui/
  art/                 the cast as SVG: Ghost (+GhostHand), Candle, Jar, WaxSeal, Emblem, Decor (Sparkles, Stars)
  components/          Cards (BuddyCard, PrintableCard, PrintableKey), CardInput (words/camera/photo), Qr
  shell.tsx            hash routes (#/seal?update), day/night atmosphere, candlelight
  grimoire.ts          makes the jar file; reads a jar from a file
  watchApi.ts          client for the watch service; in-memory jar handoff
  sound.ts             every sound synthesised with Web Audio
  styles.css           tokens, components, the cast's motion
  pages.css            page layouts, print layout
src/pages/           home, seal/ (wizard, steps, sealed, update), seance/ (circle, reveal), watch/ (preview, real watch), guides, gallery (#/gallery)
src/demo/            June's jar and cards (generated by scripts/make-demo-jar.ts)
server/dev.ts        local server: dist + /api with file storage
netlify/functions/   api.mts, watch-tick.mts (hourly)
e2e/                 run.mjs (checks), screens.mjs (screenshots)
scripts/             make-demo-jar.ts, check-offline.mjs
.kiro/               steering, specs, hooks, agents, MCP settings
```

- One component per concept; pages compose them. Page-specific CSS lives in `pages.css` under a comment header per page.
- Routes are hash routes with query params (`#/watch?manage=…`, `#/seance?jar=…`, `#/seal?update`), because the jar file has no server.
